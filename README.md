## MERN Stack CRUD App

I have an upcoming MERN Stack debugging interview where I'll be given an existing application containing an error. My task will be to identify and fix the error with AI assistance.

I'm fairly new to JavaScript. My goal is to become familiar with the structure of a MERN application, understand how its components interact, and learn how to navigate and debug an unfamiliar codebase.

### Project: Simple Task Manager

I want to build a simple MERN Stack CRUD application that allows users to:

* Create a new task.

* View all tasks.

* Update a task's title or completion status.

* Delete a task.

The application should use MongoDB, Express.js, React, Node.js, and Mongoose.

### Learning Objectives

My primary goal is to understand the architecture and data flow of a MERN application, rather than build a sophisticated application.

I want to become comfortable with:

* React components, state management, and event handling.

* Express routes, controllers, and HTTP requests.

* Mongoose models and MongoDB operations.

* Asynchronous JavaScript, particularly `async/await` and API requests.

* How data flows between the frontend, backend, and database.

* Identifying and fixing common errors in a MERN application.

### Development Plan

I want to build the application incrementally in four stages.

#### Stage 1: Backend Setup

Initialize a Node.js project, set up Express, and implement a simple API endpoint. Understand the basic structure of an Express application.

#### Stage 2: Database and CRUD Operations

Connect MongoDB using Mongoose, define a Task model, and implement the four CRUD operations. Test the backend API independently before moving to the frontend.

#### Stage 3: React Frontend

Build a simple user interface, implement React components and state management, and connect the frontend to the backend API.

#### Stage 4: Debugging Practice

Introduce common bugs and practice identifying their causes by tracing requests and data across the application.

### How I Want Codex to Help

I want to write the code myself rather than have the entire application generated for me.

Please guide me through the development process step by step, explaining the purpose of each file, component, and function.

When I encounter unfamiliar JavaScript syntax or concepts, explain them briefly and relate them to Python or C++ when useful.

When I make mistakes, help me understand the error and guide me toward fixing it rather than immediately rewriting my code.

Keep the application simple and prioritize practical knowledge that will help me navigate and debug an existing MERN application during my interview.
